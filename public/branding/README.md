# Ombra C — Stealthz

Цветные SVG и PNG скопированы без изменений из предоставленного `ombra-c-assets.zip`.
Основной знак: `#202939` и `#6E87E8`; отверстие и диагональный просвет прозрачные.

- `ombra-c.svg` — знак в интерфейсе и источник крупных системных иконок.
- `ombra-c-small.svg` и `ombra-c-16.png` — оптическая версия для 16–20 логических пикселей.
- PNG 32, 64 и 256 px — оригинальные экспорты из архива.

`npm run icons` пересоздаёт `public/favicon.svg` и PNG/ICO/ICNS в `src-tauri/icons`.
Команда использует установленный Tauri CLI и сохраняет оптическую версию для 16 px, в том числе 16 pt @2x в ICNS.
Для macOS в ICNS добавлены прозрачные поля: ширина знака — 824 px на холсте 1024 px,
чтобы видимый размер соответствовал соседним иконкам в Dock.
Монохромные ресурсы движка находятся в соседнем репозитории `ombra-engine/assets/branding`.
